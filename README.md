# Introduction to Data Analysis Using Pandas

Pandas is one of the most widely used Python libraries in data science, yet many learners skip past the fundamentals and end up confused later. This repository works through data manipulation from the ground up - creating DataFrames from raw Python objects, slicing and selecting data precisely, and reading and writing structured files. By working through the notebook, you build the muscle memory needed to handle real datasets confidently.

---

## Learning Objectives

- Construct Pandas DataFrames from arrays, dictionaries, and Series objects
- Access and modify data using label-based (`.loc`) and position-based (`.iloc`) indexing
- Read tabular data from CSV and Excel files into DataFrames
- Explore and summarize a dataset using built-in Pandas methods
- Write transformed data back to CSV and Excel formats
- Recognize when a column is a Series and use that to your advantage

## Step-by-Step Walkthrough

### Part 0 - About and Motivation

Before loading any data, the notebook frames why Pandas matters: real-world data rarely arrives clean and perfectly structured. Pandas provides a consistent interface for reshaping, filtering, and summarizing data regardless of where it came from.

### Part 1 - DataFrame Creation

The notebook starts with the most basic question: how do you get data into a DataFrame in the first place? Three paths are shown - from a NumPy array, from a Python dictionary, and from a Pandas Series. This order matters. Arrays give you shape without meaning. Dictionaries add column names. Series objects introduce the concept of an index, which becomes critical once you start aligning data from multiple sources.

The typo-prone `.loc` vs `.iloc` distinction gets its own section here rather than later, because getting indexing wrong silently produces incorrect results - Pandas will happily return an empty result or the wrong rows without raising an error.

### Part 2 - Reading and Writing Data

Reading from CSV is the most common entry point for real data. The notebook uses a graduate admissions dataset because it has enough structure (multiple categorical columns, a numeric frequency column) to make groupby operations meaningful. You see `.groupby()`, `.sum()`, and `.plot.bar()` in sequence - each building on the last to go from raw data to a visual summary in a few lines.

The Excel section is marked optional because `openpyxl` and `xlrd` are dependencies that not everyone has installed. The section still runs end-to-end and demonstrates transposing a DataFrame with `.T`, which is a useful operation regardless of file format.

### Appendix - Prerequisites and References

The appendix covers Python and NumPy prerequisites and links to external references. If you find the notebook difficult to follow, the appendix is the right place to start before re-reading.

## Key Concepts Glossary

| Term | Definition |
|------|-----------|
| **DataFrame** | A two-dimensional, labeled data structure - think of it as a spreadsheet with named rows and columns that lives in memory |
| **Series** | A one-dimensional labeled array - every column in a DataFrame is a Series |
| **Index** | The row labels of a DataFrame or Series; can be integers, strings, or datetimes |
| **`.loc`** | Label-based indexer - selects rows and columns by their names |
| **`.iloc`** | Position-based indexer - selects rows and columns by their integer position |
| **`read_csv()`** | Reads a comma-separated values file and returns a DataFrame |
| **`groupby()`** | Groups rows by the values in one or more columns so that aggregations can be applied per group |
| **`describe()`** | Returns summary statistics (count, mean, std, min, max, quartiles) for numeric columns |
| **`NaN`** | "Not a Number" - Pandas's representation of a missing value |
| **`.T`** | Transposes a DataFrame, swapping rows and columns |
| **`inplace`** | Parameter that, when set to `True`, modifies the DataFrame in place rather than returning a copy |
